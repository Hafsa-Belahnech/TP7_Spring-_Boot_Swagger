# TP 7 : Spring Boot et Swagger

# Objectifs :
- Générer automatiquement la structure de base du projet Spring Boot   
- Définir les classes et interfaces correctement annotées pour que Spring se charge du reste  
- Créer le contrôleur REST qui est responsable de la communication entre le client et le serveur
- Intégrer Swagger pour générer une documentation complète et claire des routes exposées par les contrôleurs REST
